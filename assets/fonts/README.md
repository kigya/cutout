# Manrope

Bundled unchanged variable Manrope font from Google Fonts, SIL Open Font License 1.1.
Source: https://github.com/google/fonts/tree/main/ofl/manrope
Retrieved 2026-10-18. Full license: OFL.txt.
Android asset: app/src/main/assets/fonts/Manrope.ttf; iOS references this canonical file in its Resources phase.

Android registers the variable Typeface in ReactFontManager before loading React Native, preserving numeric font weights.
